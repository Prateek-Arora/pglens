Containment filter that a GIN index can serve (R7)
A filter such as jsonb @> (contains) or ? (has key) can't use a B-tree index, so Postgres checks every
row. A GIN index stores each key or element inside the value and can answer these lookups directly. GIN
indexes are larger and slower to update than B-trees.
Docs: https://www.postgresql.org/docs/16/gin-intro.html
