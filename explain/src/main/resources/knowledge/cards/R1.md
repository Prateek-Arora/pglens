Selective sequential scan (R1)
The plan reads every row of the table and keeps only the few that pass a filter on a column. Reading
the whole table costs the same whether 5 rows match or 5 million. A B-tree index on the filtered column
lets Postgres find the matching rows directly and read only those. It helps most when few rows match.
