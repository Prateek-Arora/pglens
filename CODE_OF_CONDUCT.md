# Code of conduct

PgLens follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be kind, assume good faith, and keep discussion about the work. Harassment or abuse of any kind is
not welcome in issues, pull requests or any other project space.

To report a problem, contact the maintainer privately through
[GitHub](https://github.com/Prateek-Arora). Reports are handled confidentially, and the
Contributor Covenant's enforcement guidelines apply.
